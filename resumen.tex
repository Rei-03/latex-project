\ResumenAbstract
{%
La presente investigación desarrolló un \textbf{sistema de microservicios} para optimizar la rotación de circuitos eléctricos ante situaciones de déficit de generación en la red de distribución del sistema electroenergético cubano. Su objetivo principal fue sustituir el proceso manual actual por una herramienta computacional que analizara múltiples variables en tiempo real ---como cargas horarias (\texttt{ap\_curvas}), averías (\texttt{ap\_apagones}), circuitos asegurados (\texttt{ap\_Aseguramientos}) y restricciones operativas--- para generar órdenes de afectación y restablecimiento óptimas siguiendo directrices del Despacho Nacional de Carga. La solución implementa una \textbf{arquitectura de microservicios} con API Gateway (NestJS), microservicios especializados (\texttt{circuitos-ms}, \texttt{rotaciones-ms}, \texttt{auth-ms}) y comunicación \textbf{NATS}. La metodología combinó el análisis de requerimientos con el diseño e implementación de una aplicación web moderna utilizando \textbf{Next.js} y \textbf{React} para el frontend, estilizado con Tailwind CSS, y un backend robusto en NestJS que integró bases de datos SQL Server 2008 (SIGERE/PSFV). La gestión de estados se centralizó mediante \textbf{Hooks} y \textbf{Context API}, permitiendo una interfaz dinámica y eficiente. El algoritmo de rotación, basado en criterios FIFO por tiempo de estado, redujo el tiempo de toma de decisiones de 30--45 minutos a 2--3 segundos, con 100\% de precisión y eliminación total de errores humanos. Se concluyó que la herramienta incrementó la eficiencia operativa del Despacho Provincial de Carga y validó la transición de sistemas de escritorio a plataformas web escalables bajo metodologías ágiles. \noindent\textbf{PALABRAS CLAVE}\newline Automatización eléctrica, Rotación de circuitos, Microservicios, Next.js, NestJS, NATS, Programación Extrema (XP).
}
{%
This research developed an automated \textbf{microservices-based system} to optimize the rotation of electrical circuits during generation deficit situations in the distribution network of the Cuban power system. Its main objective was to replace the current manual process with a computational tool that analyzed multiple variables in real time---such as hourly loads (\texttt{ap\_curvas}), failures (\texttt{ap\_apagones}), secured circuits (\texttt{ap\_Aseguramientos}) and operational restrictions---to generate optimal shutdown and restoration orders following guidelines from the National Load Dispatch Center. The solution implements a \textbf{microservices architecture} with API Gateway (NestJS), specialized microservices (\texttt{circuitos-ms}, \texttt{rotaciones-ms}, \texttt{auth-ms}) and \textbf{NATS} messaging. The methodology combined requirements analysis with the design and implementation of a modern web application using \textbf{Next.js} and \textbf{React} for the frontend, styled with Tailwind CSS, and a robust NestJS backend integrating SQL Server 2008 databases (SIGERE/PSFV). State management was centralized through \textbf{Hooks} and \textbf{Context API}, enabling a dynamic and efficient interface. The rotation algorithm, based on FIFO criteria by state time, reduced decision-making time from 30--45 minutes to 2--3 seconds, with 100\% accuracy and total elimination of human errors. It was concluded that the tool increased the operational efficiency of the Provincial Load Dispatch Center and validated the transition from desktop systems to scalable web platforms under agile methodologies. \noindent\textbf{KEYWORDS}\newline Electrical automation, Circuit rotation, Microservices, Next.js, NestJS, NATS, Extreme Programming (XP).
